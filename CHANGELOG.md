# CHANGELOG

## 0.4.0

- The copy path commands take the path of the hovered link target, for example a note or a PDF. They no longer always take the path of the active note. Add the `Prefer the hovered link target` setting to turn this behavior off.

## 0.3.0

- Add hotkey commands for copy path actions (#5). Thanks to @ggfevans for the contribution.

## 0.2.0

- Add trailing slash option for folder paths (#3). Thanks to @ggfevans for the contribution.

Initial release.
